# أدوات PDF المجانية — موقع كامل جاهز للنشر

موقع أدوات PDF يعمل **100% في المتصفح** (Client-side فقط).  
لا سيرفر، لا رفع ملفات، خصوصية كاملة، مجاني، ومتوافق مع معايير جوجل (SEO + Core Web Vitals).

## الأدوات المتوفرة
- دمج ملفات PDF
- تقسيم / استخراج صفحات
- ضغط PDF (إعادة حفظ محسنة)
- تدوير الصفحات
- PDF → صور (PNG/JPEG)
- صور → PDF
- حذف صفحات

## التقنيات
- HTML5 + CSS3 حديث (RTL عربي)
- JavaScript ES6+
- pdf-lib (عبر CDN)
- PDF.js (عبر CDN)
- تصميم متجاوب وسريع

## النشر المجاني (ميزانية صفر)

### الطريقة الأسهل: GitHub Pages
1. أنشئ حساب GitHub مجاني.
2. أنشئ مستودع جديد باسم `pdf-tools` (أو أي اسم).
3. ارفع كل محتويات هذا المجلد إلى المستودع.
4. اذهب إلى Settings → Pages → Source: Deploy from branch → main / root.
5. بعد دقائق سيصبح الموقع متاحاً على:
   `https://mazooniosman299-blip.github.io/pdf-tools/`

### Cloudflare Pages (موصى به للسرعة والـ bandwidth اللامحدود)
1. سجل في Cloudflare مجاناً.
2. Workers & Pages → Create → Connect to Git → اختر المستودع.
3. Build settings: لا تحتاج build command (موقع ثابت).
4. الدومين سيكون `xxx.pages.dev` ويمكن ربط دومين مخصص لاحقاً مجاناً.

### Vercel أو Netlify
نفس الفكرة: اربط المستودع واختر Static.

## خطوات الظهور في جوجل (SEO)
1. بعد النشر غيّر كل `yourusername.github.io` في الملفات (sitemap.xml, robots.txt, canonical, og:url) إلى رابطك الحقيقي.
2. اذهب إلى [Google Search Console](https://search.google.com/search-console) وأضف الموقع.
3. أرسل الـ sitemap.xml.
4. انتظر الفهرسة (أيام إلى أسابيع).
5. أضف محتوى إضافي (مقالات قصيرة عن كيفية استخدام كل أداة) لتحسين الترتيب.

## الربح (Monetization)
- بعد وجود زيارات ومحتوى كافٍ: قدم على **Google AdSense**.
- ضع كود الإعلان في الأماكن المحددة (`.ad-placeholder`).
- بدائل: إعلانات أخرى، روابط تابعة، أو تبرعات (Buy Me a Coffee / Ko-fi).

**ملاحظات AdSense:**
- يحتاج دومين (حتى لو فرعي في البداية قد يُرفض — الأفضل دومين خاص لاحقاً).
- محتوى أصلي + صفحات خصوصية / عن / اتصل بنا (موجودة بالفعل).
- لا تنتهك سياسات Google.

## تخصيص
- غيّر الألوان في `css/style.css` (متغيرات CSS).
- أضف أدوات جديدة بسهولة بنفس نمط الصفحات الموجودة.
- للغات إضافية: انسخ الصفحات وعدّل النصوص.
